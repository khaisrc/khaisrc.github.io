A terminal UI that fills a gap in Claude Desktop: archived sessions can't be unarchived through the app itself. This tool lets you manage session files directly — browse by last-modified, type-to-filter, multi-select, and take actions like view, delete to Trash, or archive/unarchive.

Works with Claude Code CLI transcripts, Claude Desktop sessions, and Cowork sessions. Distributed as prebuilt binaries for macOS (Intel and Apple Silicon) via GoReleaser.
